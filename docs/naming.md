# Naming

## Current name

**deedum**: from Tweedledum and Tweedledee (Czech Tydliták and Tydlitek). It was the
name of a 2020–21 plan to pull a small static generator, copied between several repos,
into one package ([research](research/old-do-py-generators.md)). The plan never got
built; this is it. Free on PyPI (checked 2026-11-18).
